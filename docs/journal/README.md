# Aether Forensic Journal

One entry per session. Entries are the engineering record — decisions,
failures, and measurements are as important as successes.

## Naming convention
YYYY-MM-DD-NNN-slug.md (NNN = zero-padded sequence, slug = 2-4 words)
Example: 2025-05-23-001-cleanup-baseline.md

## Entry structure (required sections)
**Session goal** — one sentence, what you set out to do
**Decisions made** — with reasoning, not just the outcome
**What happened** — honest account, including failures and dead ends
**Measurements** — any numbers (test counts, latency, token costs, scores)
**Next session** — exact start state so you can resume cold

## Rules
- Under 500 words per entry (engineering notes, not essays)
- Write it before closing the terminal, not the next day
- If a measurement was skipped, say why
